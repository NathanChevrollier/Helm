# Sécurité

Zenytt manipule des accès sensibles (clés SSH, mots de passe, accès root) : les failles de sécurité
sont traitées en priorité.

## Signaler une faille

**Ne publie pas la faille dans une issue publique.** Signale-la de façon confidentielle :

1. de préférence via GitHub : onglet **Security** du dépôt → **Report a vulnerability** ;
2. sinon par e-mail à l'adresse indiquée dans les [mentions légales](docs/legal/mentions-legales.md).

Indique la version de Zenytt, le système, les étapes pour reproduire et l'impact estimé.

Tu recevras un accusé de réception sous 7 jours. Une fois la correction publiée, la faille est
décrite dans les notes de version, avec ton nom si tu le souhaites.

## Versions maintenues

Seule la dernière version publiée reçoit des correctifs de sécurité. Les mises à jour
automatiques de Zenytt permettent de l'obtenir sans rien faire.

# Security (English)

Please report vulnerabilities privately through GitHub (**Security** tab → **Report a
vulnerability**), not in public issues. Only the latest release receives security fixes.
