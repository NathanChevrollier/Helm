# Contribuer à Zenytt

Merci de ton intérêt ! Les signalements de bugs et les idées sont bienvenus dans les
[issues](https://github.com/NathanChevrollier/Zenytt/issues). Pour une faille de sécurité, suis
plutôt [SECURITY.md](SECURITY.md).

## Avant une pull request

- Ouvre d'abord une issue pour discuter d'un changement important.
- Messages de commit au format Conventional Commits : `type(portée): message`.
- `pnpm test` et `pnpm typecheck` doivent passer.

## Droits sur les contributions

Zenytt est publié sous une licence « source disponible » ([PolyForm Shield 1.0.0](LICENSE)) et son
éditeur peut être amené à le proposer sous d'autres licences. Pour que ce soit possible, en
soumettant une contribution (code, documentation, traduction, image…) :

1. tu certifies en être l'auteur, ou avoir le droit de la soumettre, et qu'elle ne contient pas
   de code soumis à une licence incompatible (GPL, AGPL…) ;
2. tu accordes à Nathan Chevrollier une licence mondiale, gratuite, non exclusive, irrévocable et
   pour toute la durée des droits, d'utiliser, reproduire, modifier, distribuer et
   **sous-licencier** ta contribution, y compris sous d'autres licences, commerciales ou non ;
3. tu restes propriétaire de ta contribution et libre de l'utiliser ailleurs.

Coche la case correspondante dans la description de la pull request pour l'indiquer.
